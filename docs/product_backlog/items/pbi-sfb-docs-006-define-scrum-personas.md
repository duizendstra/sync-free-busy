## 1. PBI Goal & Justification
**Goal:** To complete the THEA team model by defining the core competencies, objectives, and engagement triggers for the essential Scrum team personas.
**Justification:** The current persona profiles for roles like `Helms`, `Bolt`, and `QA-Bot` are empty placeholders. Completing them is crucial for understanding project execution roles, for effective role-playing by AI assistants, and for providing a complete onboarding guide for new team members.

## 2. Acceptance Criteria
- **AC1:** The `Helms` (Scrum Master) persona profile is fully defined and documented.
- **AC2:** The `Bolt` (Software Developer) persona profile is fully defined and documented.
- **AC3:** The `QA-Bot` (Quality Assurance) persona profile is fully defined and documented.
- **AC4:** The `Scribe` (Technical Writer) persona profile is fully defined and documented.
- **AC5:** The `Guardian` (Security & Compliance) persona profile is fully defined and documented.
- **AC6:** The `team-handbook.md` is reviewed to ensure it correctly references and summarizes these core roles.
