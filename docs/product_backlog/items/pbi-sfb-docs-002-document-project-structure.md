## 1. PBI Goal & Justification
**Goal:** To add a clear, concise section to the root `README.md` that explains the project's "products, factory, docs" structural philosophy.
**Justification:** The current repository structure is logical but not self-explanatory. Without this documentation, new developers will be confused about where to find code, automation, and project management artifacts. This is a critical piece of onboarding documentation.

## 2. Acceptance Criteria
- **AC1:** The root `README.md` file is updated with a new section (e.g., "How This Repository is Organized").
- **AC2:** The new section clearly and concisely explains the purpose of the `products/` directory.
- **AC3:** The new section clearly and concisely explains the purpose of the `factory/` directory.
- **AC4:** The new section clearly and concisely explains the purpose of the `docs/` directory.
- **AC5:** The explanation is tailored specifically for the SyncFreeBusy project.
